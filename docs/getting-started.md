# はじめてガイド — Cowork から Claude Code へ

Claude の Cowork を使ったことがある人が、Claude Code を使い始めるときのガイド。迷ったらここに戻ってくる。

## Cowork と Claude Code の違い

| | Cowork | Claude Code |
|---|---|---|
| 何に向いているか | 資料づくり・調べもの・ファイルの整理 | それに加えて、パソコンの中のファイルやツールを直接動かす作業 |
| 作業の場所 | 会話ごとに渡したファイル | **開いたフォルダ**の中（そのフォルダのファイルを読み書きする） |
| 覚えておくこと | 会話の中だけ | `CLAUDE.md`（ルール）と**スキル**（手順書）を、毎回自動で読む |
| 確認の画面 | ほとんど出ない | ファイルを書き換える・コマンドを動かす前に「許可しますか？」と聞かれる |

いちばん大きな違いは「**どのフォルダで開くか**」。Claude Code は開いたフォルダの中を見て作業する。

## 最初にやること

### 1. 作業フォルダを作る

仕事のまとまりごとにフォルダを1つ作り、そのフォルダで Claude Code を開く。

```
~/work/
├── 〇〇プロジェクト/
└── 議事メモ/
```

「`~/work/議事メモ` というフォルダを作って」と頼めば作ってくれる。

### 2. 確認の画面に慣れる

Claude Code は、ファイルを書き換える前やコマンドを動かす前に許可を求める。最初のうちは、

- 何をしようとしているか分からなければ「これは何をするの？」と聞く
- 分かったら「許可」を押す

で十分。慣れてきて「この確認はもう要らない」と思ったら、「この種類の確認を減らしたい」と頼めば設定してくれる。

### 3. 全体ルールを育てる

`~/.claude/CLAUDE.md` は、どのフォルダで開いても Claude Code が守るルール。「いつも〇〇してほしい」と思ったら、

```
全体ルールに「〇〇する」を足して
```

と頼めば書き足してくれる。

## 入っているスキルと話しかけ方

スキルは「こう頼まれたら、この手順でやる」という手順書。話しかけ方を変えるだけで呼び出せる。

| スキル | 何をしてくれるか | 話しかけ方の例 |
|---|---|---|
| grill-me | 計画やアイデアを1問ずつ深掘りし、抜けている論点を一緒に埋める | 「この計画をグリルして」 |
| writing-proposals | 誰かに出す提案書を、対話で材料を集めてから書く | 「部長に〇〇を提案したい。提案文を作って」 |
| plain-writing | 文章を、結論から先に読みやすく直す | 「このSlackの文面を伝わる文章にして」 |
| meeting-notes | 打ち合わせの文字起こしから議事メモを作る | 「この文字起こしで議事メモ作って」（txt を一緒に渡す） |

使い方のコツ: **やりたいことを、そのまま日本語で話す**だけでよい。スキル名を覚える必要は無い。

## スキルを最新にする

配布元でスキルが改善されたら、次のように頼む:

```
スキルを更新して（~/shared-agent-skills で git pull）
```

スキルはリンクで入っているので、これだけで最新になる。

## 自分のスキルや設定を作りたくなったら

- 自分専用のスキルは `~/.claude/skills/<スキル名>/SKILL.md` に作る。「〇〇のスキルを作って」と頼めば作ってくれる
- **`~/shared-agent-skills` の中は書き換えない。** ここは配布元のコピーで、更新のときに書き換えた内容がぶつかる
- 配られたスキルを自分用に改造したくなったら、「shared-agent-skills を自分の GitHub にフォークして切り替えたい」と頼む。**ただしフォークは公開になる**ので、仕事の情報や人の名前は書かない。自分だけのものは、非公開のリポジトリに置く

## 困ったとき

| 困りごと | こう頼む |
|---|---|
| スキルが呼ばれない | 「スキルが入っているか確かめて（`bash ~/shared-agent-skills/setup/install.sh --check`）」。直らなければ Claude Code を開き直す |
| 何が起きたか分からない | 「いま何をしたか、やさしく説明して」 |
| 元に戻したい | 「さっきの変更を元に戻して」 |
| 録音から直接文字起こししたい | 「`~/shared-agent-skills/docs/whisper-addon.md` を読んで whisper を入れて」 |
